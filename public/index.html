Add a machine

Create a join link and send it to whoever owns the machine, as a command they run in a terminal. The machine starts reporting here within seconds. The link works once, for a short while.

This console listens on this machine only, so a link made now works only here. To add another computer, stop the console and start it again with --listen 0.0.0.0.
