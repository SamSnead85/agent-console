Why a command, what it checks, and the form to type by hand

Their machine needs Node.js 22 or newer (free from nodejs.org). The command downloads Agent Console from its GitHub release over HTTPS and runs nothing until the file matches the release's SHA256SUMS (that check is the part shown as '…'); the join itself travels over TLS pinned to this console's certificate. The link opens a page that shows the same command, but that page comes over plain HTTP, so on a network you do not fully trust, send the command. Once joined, only counts, model names, times and salted hashes leave that machine — never a prompt, a reply, a file path or file contents.
