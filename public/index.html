Agent Console — what everything means
j / k
move the roster cursor
space
expand the agent tree for the row under the cursor
g
jump to the top burner
/
filter by project, branch, model, session id or activity
c
show or fold the cold sessions
p / s / f
toggle the processes, shipped and fleet drawers
o / e
toggle the projects list and the effort (token-to-shipped-work) drawers. There is no sessions drawer: every session, on this machine and declared from elsewhere, is a row in the table.
t
cycle the history period (hour · 24h · 3 days · everything recorded)
n
cycle the project scope, or press again to return to all projects
u, or click the burn figure
swap which burn unit is the large one. Both are always on screen; the figure itself provides the same action without a shortcut. See tok/min · tok/s under terms.
enter / space
on the focused “remaining ▸” toggle in the project progress strip, open or fold the remaining-work list. Clicking it does the same.
esc
release the roster, so the row order can settle again
a
acknowledge all latched alarms
?
this reference. Any underlined word on the screen opens it at that term.
