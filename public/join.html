This console is a demonstration. Its links show the steps but cannot add a real computer.

  1. Check you have Node.js 22 or newer. Open a terminal — Terminal on a Mac, PowerShell on Windows — type node --version and press Return. If it says v22 or higher, carry on. If not, install the LTS version from nodejs.org first.
  2. Paste this into the terminal and press Return. — The code in it (shown masked) works once and expires within the hour. The command downloads Agent Console … from its GitHub release over HTTPS and runs nothing until the file's SHA-256 matches the release's SHA256SUMS; that check is the text between the first two single quotes. Check that it starts with node -e, names https://github.com/SamSnead85/agent-console/releases/download/, and ends with your link in single quotes, with nothing after it, and that the check is the published one: its SHA-256 is listed in the project's README (“The check in every command”) and on the release page, with a short command that prints the SHA-256 of the check in a command you paste into it. The eight dots stand for your code; Copy gives it in full. This page reaches you over plain HTTP, so if whoever sent the link also sent the command, run theirs. The SHA-256 it prints is also on its release page. It then joins over TLS, accepting only the certificate named in your link.
  3. Leave that window open. This computer appears on the console within a few seconds. Closing the window stops reporting; this command starts it again, no new link needed: —
