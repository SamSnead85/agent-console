Once it is added, this computer reports how much its AI coding agents use — tokens, models, cache reads and writes — to that console, every few seconds, until you close the window.

What leaves this computer

Only token counts, model names, times, and salted hashes of session and project identifiers.

Never a prompt, a reply, a file path, or the contents of a file. The rule is enforced in code, and a test proves it.

This console is a demonstration. Its links show the steps but cannot add a real computer.

  1. Check you have Node.js 22 or newer. Open a terminal — Terminal on a Mac, PowerShell on Windows — type node --version and press Return. If it says v22 or higher, carry on. If not, install the LTS version from nodejs.org first.
  2. Paste this into the terminal and press Return. — The code in it (shown masked) works once and expires soon. It fetches Agent Console from that computer, not from a public registry, and starts reporting.
  3. Leave that window open. This computer appears on the console within a few seconds. Closing the window stops reporting; npx --yes … report starts it again, no new link needed.
